# Wolves in Switzerland: source material

Archived from the original standalone repo `geovis2_versionfinale`
(GeoVis2 project, "Suivi de la population des loups en Suisse").

The app itself (HTML/CSS/JS and the GeoJSON data) lives under `static/lupi/`
and was verified identical to the original repo. The only unique material
kept here is the project report:

- `rapport/rapport_def.pdf`: final report.
- `rapport/rapport_esquisse.Rmd`: R Markdown source of the report.
- `README_geovis2.md`: original repo README.
